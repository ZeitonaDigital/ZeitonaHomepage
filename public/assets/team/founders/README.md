# Founder profile images

Place the approved, site-hosted founder portraits in this directory using these exact filenames:

- `diogenes-vaz-melo.jpg`
- `fabricio-oliveira.jpg`

Image guidance:

- preferred format: JPEG (`.jpg`);
- preferred aspect ratio: 4:5 portrait;
- recommended dimensions: 1200 × 1500 pixels;
- minimum dimensions: 800 × 1000 pixels;
- keep the face reasonably centred so `object-fit: cover` works at desktop and mobile sizes.

After both files are supplied, update the two rendered founder image sources in `about.html` to:

- `assets/team/founders/diogenes-vaz-melo.jpg`
- `assets/team/founders/fabricio-oliveira.jpg`

Do not use LinkedIn CDN URLs as permanent runtime sources.
